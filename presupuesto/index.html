Como se calcula

No hay un precio unico para instalar un aire. Hay una suma de factores medibles. Esto es lo que mira el tecnico.

trabajo = mano_de_obra(frigorias) x cantidad cañeria = (metros_reales - 3) x precio_por_metro altura = piso_y_acceso(planta_baja | 2do_3er | mas_de_3er | rappel) instal. = electrico + desague + perforacion_pared traslado = zona(distancia_desde_base) descuento= preinstalacion_existente + cantidad_de_equipos total = trabajo + cañeria + altura + instal. + traslado - descuentos

Por eso no se puede dar un numero exacto sin ver el lugar: la cañeria, la altura y el acceso cambian el resultado. La calculadora te da el rango antes de la visita.
